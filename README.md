# Personal Todo — Android

A single-user, offline-first Android productivity app starter built with Kotlin, Jetpack Compose, Material 3, Room, and local notifications.

## Open
Open the `PersonalTodo` folder in Android Studio and let Gradle sync.

## Current implementation
- Local Room task persistence
- Add/complete/delete tasks
- Search
- Today / Completed / All views
- Priority and category
- Due-date display model
- Local notification receiver and reminder scheduler foundation
- Material 3 UI
