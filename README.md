# DayFlow 🌙

A personal, offline-first Android productivity app for managing everyday tasks, recurring tasks, reminders, task history, and personal expenses.

> **AI-Assisted Project**
>
> DayFlow was developed with significant assistance from AI coding tools.
> AI was used for code generation, implementation, debugging, UI development, and feature development.
> The project was directed, reviewed, tested, and refined during development.
>
> This repository is shared transparently as an AI-assisted learning and experimentation project.

---

## ✨ Features

### 📊 Dashboard

A central overview of your productivity and spending.

- Pending task statistics
- Completed task statistics
- Today's task statistics
- Task completion percentage
- Recurring task overview
- Expense statistics
- Monthly spending overview
- Category-wise expense information
- Recent activity

### ✅ Todo

Manage everyday tasks with a clean and simple interface.

- Create tasks
- Complete tasks
- Delete tasks
- Task descriptions/notes
- Task categories
- Priority levels
  - 🔴 High
  - 🟠 Medium
  - 🟢 Low
- Search tasks
- Sort tasks
- Today view
- Recurring tasks
- Completed tasks
- Task history
- Task creation date and time
- Task completion date and time
- Due dates
- Local notifications and reminders

### 🔁 Recurring Tasks

Create tasks that repeat automatically according to a schedule.

For example:

- Every Wednesday
- Every Saturday
- Other supported recurring schedules

Recurring tasks are managed separately from normal tasks while remaining part of the Todo system.

### 📜 History

View previous tasks and their activity.

Completed tasks retain the date and time at which they were completed.

### 🔔 Notifications

Local task reminders can be scheduled on the device without requiring a backend service.

### 💰 Expense Tracker

Track personal spending using fixed expense categories.

#### Categories

- 🍔 Food
- 🚌 Transport
- 📚 Education
- 🛍️ Shopping
- 🎮 Entertainment
- 💻 Subscriptions
- 🏠 Other

Add individual expenses by specifying:

- Amount
- Category
- Description/name
- Date

The app automatically calculates:

- Monthly total spending
- Category-wise spending
- Individual transactions
- Spending for different months

Example:

```text
September 2026

🍔 Food             ₹1,650
🚌 Transport          ₹680
📚 Education        ₹1,200
🛍️ Shopping           ₹450
🎮 Entertainment       ₹0
💻 Subscriptions      ₹299
🏠 Other                ₹1

Total Spent:        ₹4,280
